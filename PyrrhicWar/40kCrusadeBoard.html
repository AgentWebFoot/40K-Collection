Website Controls

  • Click a tile to select it and open its details for editing or review.
  • Hold Shift and click to select multiple tiles at the same time.
  • Use Apply to stage tile edits before saving or submitting them.
  • Use Submit Edit Request to send a participant request for review.
  • Use Save in admin mode to apply edits directly to the live map.
  • Use Left Click to move around the map.
  • Use Mouse Wheel to zoom in and out.
  • Select a building project here before adding or removing build points from that project.
  • When a tile is at its maximum control value, that value may stay hidden until the tile is clicked.
